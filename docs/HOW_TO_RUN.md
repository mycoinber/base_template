# Run Guide

## Current Runtime Shape

The project runs through the consolidated `core + theme` path:
- page routes: `pages/index.vue`, `pages/[...slug].vue`
- data fetching: `core/composables/usePageData.ts`
- document/head assembly: `core/composables/usePageDocument.ts`
- SEO/schema: `core/composables/useSeo.ts`
- navigation: `core/composables/useNavigation.ts`
- site manifest: `core/composables/useSiteManifest.ts`
- UI layer: `themes/<active-theme>/*`

Top-level frontend folders `components/*` and `composables/*` are no longer part of runtime.

## Theme Selection Model

Theme selection is env-driven and happens before Nuxt starts:
- `ACTIVE_THEME` selects one theme for the current dev/build/deploy
- Nuxt layer `extends`
- `@theme` alias
- `Theme*` component auto-imports
- Tailwind content scanning

all point to that one active theme

This means the repo supports many themes, but one running app instance uses one selected theme.

## Required Environment

Expected `.env` variables:

```bash
SITE_ID=...
BACKEND_URL=...
SITEMAP_API_BASE=...
MEDIA_STORAGE_URL=...
SLUG=...
ACTIVE_THEME=parimatch
```

Theme color overrides are read from `NUXT_PUBLIC_COLOR_*`.

The current theme layer expects these semantic color keys when you want full repaint control:
- `NUXT_PUBLIC_COLOR_PRIMARY`
- `NUXT_PUBLIC_COLOR_SECONDARY`
- `NUXT_PUBLIC_COLOR_ACCENT`
- `NUXT_PUBLIC_COLOR_BG_PRIMARY`
- `NUXT_PUBLIC_COLOR_BG_SECONDARY`
- `NUXT_PUBLIC_COLOR_TEXT_PRIMARY`
- `NUXT_PUBLIC_COLOR_TEXT_SECONDARY`
- `NUXT_PUBLIC_COLOR_TEXT_HEADING`
- `NUXT_PUBLIC_COLOR_TEXT_INVERSE`
- `NUXT_PUBLIC_COLOR_TEXT_CONTRAST`
- `NUXT_PUBLIC_COLOR_BORDER`
- `NUXT_PUBLIC_COLOR_STATE_HOVER`

## Runtime Notes

- `public/site-manifest.json` is generated by `scripts/fetch-manifest.mjs`
- active theme is selected in `theme.config.ts` from `ACTIVE_THEME`
- `/api/pages` and `/api/nav` proxy requests to backend services
- `pages/[...slug].vue` is the canonical catch-all page route

## Adding A New Theme

1. Create `themes/<name>/`
2. Add `components/`, `layouts/`, `tokens/`, `theme.config.ts`, `tailwind.preset.ts`
3. Register the theme in root `theme.config.ts`
4. Set `ACTIVE_THEME=<name>` in `.env`
5. Restart Nuxt
