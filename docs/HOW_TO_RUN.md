# Run Guide

## Current Runtime Shape

The project runs through the consolidated `core + theme` path:
- page routes: `pages/index.vue`, `pages/[...slug].vue`
- data fetching: `core/composables/usePageData.ts`
- document/head assembly: `core/composables/usePageDocument.ts`
- SEO/schema: `core/composables/useSeo.ts`
- navigation: `core/composables/useNavigation.ts`
- site manifest: `core/composables/useSiteManifest.ts`
- UI layer: `themes/parimatch/*`

Top-level frontend folders `components/*` and `composables/*` are no longer part of runtime.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

Dev server:

```text
http://localhost:3000
```

## Production Build

```bash
npm run build
```

Preview the built app:

```bash
npm run preview
```

## Required Environment

Expected `.env` variables:

```bash
SITE_ID=...
BACKEND_URL=...
SITEMAP_API_BASE=...
MEDIA_STORAGE_URL=...
SLUG=...
```

Theme color overrides are read from `NUXT_PUBLIC_COLOR_*`.

## Runtime Notes

- `public/site-manifest.json` is generated by `scripts/fetch-manifest.mjs`
- active theme is selected in `theme.config.ts`
- `/api/pages` and `/api/nav` proxy requests to backend services
- `pages/[...slug].vue` is the canonical catch-all page route

## Known Limitations

- only one validated theme is active today: `themes/parimatch`
- `docs/MIGRATION.md` is a historical migration plan, not the current source of truth
