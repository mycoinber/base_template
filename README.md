# Base Template

Nuxt 3 SSR template with:
- `core` headless/business layer
- theme layer in `themes/*`
- one active theme per build selected from `.env`
- Nitro proxy routes to backend API
- SEO/schema/head assembly centralized in `core/composables`

## Architecture Contract

The project supports multiple themes, but the selection model is deployment-level:
- one active theme is resolved before Nuxt build/dev starts
- the selected theme is controlled by `ACTIVE_THEME` in `.env`
- Nuxt `extends`, aliases, Tailwind content paths, and `Theme*` auto-imports are all bound to that active theme

This is not a runtime theme switcher for one browser session. It is a fast way to run or deploy the same codebase with different branded themes.

## Canonical Runtime

The runtime path is consolidated around:
- page data: `core/composables/usePageData.ts`
- page document/head setup: `core/composables/usePageDocument.ts`
- SEO/schema: `core/composables/useSeo.ts`
- navigation: `core/composables/useNavigation.ts`
- site manifest: `core/composables/useSiteManifest.ts`
- themed UI: `themes/<active-theme>/*`

## Run

Install dependencies:

```bash
npm install
```

Start dev server:

```bash
npm run dev
```

Production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Required Environment

Expected `.env` variables:

```bash
SITE_ID=...
BACKEND_URL=...
SITEMAP_API_BASE=...
MEDIA_STORAGE_URL=...
SLUG=...
ACTIVE_THEME=parimatch
```

Theme color overrides are read from `NUXT_PUBLIC_COLOR_*`.

## Theme Registry

Available themes are registered in `theme.config.ts`.

Current contract:
- add a theme under `themes/<name>`
- register it in `theme.config.ts`
- set `ACTIVE_THEME=<name>` in `.env`
- restart `npm run dev` or rebuild production

## Runtime Flow

1. Nuxt page loads `pages/index.vue` or `pages/[...slug].vue`
2. page data is fetched through `/api/pages` via `usePageData`
3. head/meta/schema/body code blocks are assembled in `usePageDocument`
4. layout/theme components render through `Theme*` components from the active theme layer
5. navigation is fetched through `/api/nav`

## Notes

- `public/site-manifest.json` is generated by `scripts/fetch-manifest.mjs`
- active theme is resolved in `theme.config.ts` from `ACTIVE_THEME`
- `pages/[...slug].vue` is the canonical catch-all route
