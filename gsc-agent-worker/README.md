# FastGen GSC Agent Worker

This Worker syncs GSC daily summary data from the mini-site side and sends aggregated rows back to FastGen.

Production flow is automatic:

1. User pastes the site service account JSON in FastGen admin.
2. User redeploys the site.
3. Backend passes encrypted GSC agent config to `deploy_worker`.
4. `deploy_worker` deploys this Worker and uploads secrets with Wrangler.

Manual commands are only for local debugging:

```bash
wrangler secret put GSC_SERVICE_ACCOUNT_JSON
wrangler secret put GSC_AGENT_SECRET
wrangler deploy
```

Runtime vars are generated by deploy_worker:

```toml
BACKEND_URL = "https://backend.example.com"
SITE_ID = "..."
GSC_AGENT_ID = "..."
GSC_DAYS_BACK = "14"
```

The cron wakes every 15 minutes, but the backend lease returns `due: true` only when the site is due. Backend sets the default interval to 180 minutes, so sync timing is offset per worker/site instead of one global batch.
